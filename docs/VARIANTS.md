# Variant inventory

Generated by `tools/catalog_variants.py` from the pinned upstream files.

**Inventory is not certification.** `Native` means a source rule implementation exists. Runtime advertisement, rule tests, and release approval are separate evidence. No game is promoted to release-approved by this script.

## Source and architecture

- Fairy-Stockfish commit: `9f778da667f6e07dae1e85d3e2ea204fc6dee94d`
- Compiled registrations in source: 121 (includes aliases).
- INI example sections: 143; these require explicit loading.
- Core limit: two players, rectangular boards up to 12 files × 10 ranks with LARGEBOARDS.
- Source geometry and rule expressions are extracted hints, not evaluated C++ state.
- Bughouse/Supply board rules do not provide a complete synchronized two-board match.

Runtime handshake advertised **121** variant IDs.
Engine SHA-256: `7dbb3e00afbfc04ef80875852d23ca14b75341845b8cad31666de49c24bb3bef`.
